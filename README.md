# Aviassembly Mods

A collection of Aviassembly mods, including a wing flap project covering multiple wing types.

- [Wing Flaps](Flaps/) — wing flap modifications and one shared wing model viewer. Big Wing v0.20 is available; Straight Wing flaps are in development.
- [Download the wing viewer](https://github.com/HotBowl1080/Aviassembly-Mods/raw/refs/heads/main/Flaps/aviassembly-wing-preview.zip) — extract the single HTML file and choose a wing from its dropdown.
- [Editor Tools](EditorTools/) — camera focus, precision movement and rotation, and temporary part hiding.
- [Wing Inspector](WingInspector/) — development tool for inspecting native wing geometry.

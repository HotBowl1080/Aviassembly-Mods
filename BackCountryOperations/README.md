# BackCountry Operations 0.29.0

[Download BackCountryOperations.dll](https://github.com/HotBowl1080/Aviassembly-Mods/raw/refs/heads/main/BackCountryOperations/BackCountryOperations.dll) · [SHA256](SHA256.txt)

The opening earthquake damages Forest Island airfields. Displaced runway slabs load individual wheels, so touchdown placement and speed matter. Bring a Runway Patch Kit to the gravel SERVICE stand at The Wind Turbines, or deliver a Hospital Pavement Kit from Base after restoring the Hospital’s power.

Repaired runways can support further upgrades and heavier freight. The Wind gravel turnarounds have wider entrances, construction plays a brief dust and compactor effect, and airfield rendering and loading use less work.

## Installation

1. Close Aviassembly and make sure BepInEx 5 is installed.
2. Copy `BackCountryOperations.dll` into `BepInEx/plugins/`, replacing any previous BackCountry Operations DLL. Keep one copy of the plugin.
3. Start the game and check that BepInEx reports BackCountry Operations **0.29.0**.

The earlier [v0.75-MaybeAndrewWillAndrew build](https://github.com/HotBowl1080/Aviassembly-Mods/raw/refs/heads/main/BackCountryOperations/BackCountry%20Operations%20v0.75-MaybeAndrewWillAndrew.dll) is still available. It identifies itself in BepInEx as 0.27.0.

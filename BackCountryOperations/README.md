# BackCountry Operations v0.75-MaybeAndrewWillAndrew

[Download the mod DLL](https://github.com/HotBowl1080/Aviassembly-Mods/raw/refs/heads/main/BackCountryOperations/BackCountry%20Operations%20v0.75-MaybeAndrewWillAndrew.dll) · [SHA256](SHA256.txt)

The opening earthquake damages Forest Island airfields. Broken pavement and washed out dirt affect individual wheels during landing and rollout. Deliver a Runway Patch Kit to the gravel SERVICE stand at The Wind Turbines, then fly recovery shipments to reopen the island’s routes. Base stays operational. Village lighting upgrades use a dedicated Runway Lighting System from Base.

## Installation

1. Close Aviassembly and make sure BepInEx 5 is installed.
2. Rename the downloaded DLL to `BackCountryOperations.dll` and place it in `BepInEx/plugins/`, replacing any previous copy of BackCountry Operations. Keep one copy of the plugin.
3. Start the game. The BepInEx log identifies this binary as BackCountry Operations **0.27.0**. Its public download label is **v0.75-MaybeAndrewWillAndrew**.
